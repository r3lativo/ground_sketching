Abstract

Text-only Large Language Models (LLMs) struggle with reasoning in situated, embodied tasks, in part because they lack the visual and spatial grounding that humans rely on. Trained on "space-less, time-less" text, these models often fail to resolve ambiguities or track references that would be obvious from shared visual context. We address this gap with a system that compositionally generates a visual representation — a "mental imagery" — directly from conversational utterances. This sketch acts as a persistent, grounded representation of the situational context, which we hypothesize helps an agent form associations more easily and improves its reasoning and question-answering capabilities. Our pipeline combines an image generation model with a Visual Language Model (VLM) acting as a "prompt polisher", translating abstract conversational intent into the precise, detailed prompts required for compositional image editing.
